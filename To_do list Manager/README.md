# To-Do List Manager (CLI)

A clean and simple command-line To-Do List application built with Python.

## Features

- Add new tasks
- View all tasks with clear status (Pending / Completed)
- Mark tasks as completed
- Delete tasks
- Automatic data persistence using JSON (tasks are saved even after closing the program)

## How to Run

python todo.py

## Requirements

- Python 3.8 or higher
- No external libraries required

## Project Structure

- todo.py — main application
- tasks.json — automatically created file that stores your tasks
- .gitignore — ignores unnecessary files
