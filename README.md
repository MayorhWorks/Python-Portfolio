# Personal Expense Tracker (CLI)

A simple command-line expense tracker written in Python.

## Features

- Add expenses (amount, category, description, date)
- List all expenses
- View totals by category
- View totals by month
- Data is automatically saved to a JSON file

## How to Run

```bash
python "tracker.py"
```

## Requirements

- Python 3.8+

No external libraries needed.

## What I Learned

- Working with lists and dictionaries
- File handling with JSON
- Input validation and error handling
- Building a simple interactive menu
